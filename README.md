Udemy-Inspired Learning Dashboard
A responsive, front-end learning dashboard inspired by online learning platforms. The interface presents learning categories, scheduled classes, course progress, promotional banners, upcoming events, and a footer with support and contact information.

This project demonstrates the use of HTML and CSS to build a structured, visually engaging educational website interface.

✨ Features
Navigation bar — Displays the Udemy brand, navigation menu, and profile section.

Hero section — Introduces the learning platform with a promotional banner and call-to-action button.

Learning categories — Displays categories such as Skills, Subjects, Quiz, and Games.

Today's classes — Shows sample classes for Mathematics, English, Hindi, Science, and Arabic, with completion indicators.

Learning banner — Includes a promotional section encouraging users to join demo classes.

Upcoming events — Displays event cards with images and ticket-availability labels.

Call-to-action section — Provides a contact-oriented section for users who have questions.

Footer — Contains sample About, Support, and Contact Us information.

Responsive layout — Uses CSS media queries to adapt the layout for tablet and mobile screen sizes.

🛠️ Technologies Used
HTML5 — Structures the website and its content.

CSS3 — Handles styling, layout, colours, gradients, cards, and responsive behaviour.

Flexbox — Aligns navigation elements and other interface components.

CSS Grid — Organizes learning categories, class cards, event cards, and footer sections.

Unsplash — Provides externally hosted images for the events section.

🚀 Getting Started
Prerequisites
You only need a modern web browser. No backend, package installation, or build tools are required to view the current version.

Run Locally
Clone the repository:

git clone https://github.com/ahmedazha9-art/School-website.git
Navigate to the project directory:

cd School-website
Open index.html in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

⚙️ Implementation Details
The website uses a single HTML file with CSS embedded in a <style> element.

Local PNG images are referenced using relative file paths.

Event images are loaded from external Unsplash URLs.

CSS Grid and Flexbox provide the primary layout structure.

Media queries adjust the layout at narrower screen widths.

⚠️ Current Limitations
This project is a front-end interface prototype rather than a complete learning management system.

Navigation items are primarily visual and are not connected to separate pages.

Call-to-action buttons do not currently implement functional actions.

Class completion and progress indicators display sample content rather than live user data.

The event cards do not have a functional ticket-booking system.

There is no authentication, database, or backend integration.

The contact information and event content are placeholders.
